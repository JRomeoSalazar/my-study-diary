# MCPs Starter Pack

- [Google DevTools (Google)](https://github.com/ChromeDevTools/chrome-devtools-mcp/): El agente abre tu web en el navegador, la prueba, lee la consola y hace capturas.
- [Context7 (Upstash)](https://context7.com/):Le da al agente la documentación actualizada de cualquier librería o framework.
- [GitHub (GitHub)](https://github.com/github/github-mcp-server): Gestiona repositorios, issues y pull requests desde el agente.
- [Figma (Figma)](https://www.figma.com/es-es/mcp-catalog/): Convierte diseños de Figma en código usando el contexto real del diseño.
- [Supabase (Supabase)](https://supabase.com/docs/guides/ai-tools/mcp): Crea y consulta bases de datos directamente desde el agente.
